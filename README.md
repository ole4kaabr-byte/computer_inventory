# Учёт компьютерной техники

Проект для управления данными о оборудовании с использованием SQLite и Python.

## Структура проекта

- `sql_scripts/` — SQL-скрипты для создания таблицы и вставки данных
- `src/` — исходный код на Python

## Использование

1. Создайте базу данных и таблицу, запустив SQL-скрипты.
2. Запустите `equipment_manager.py` для выполнения операций с данными.
